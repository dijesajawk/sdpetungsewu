# BAB V PENUTUP

## 5.1 Kesimpulan

1. Web Edukasi menyediakan alur lengkap: guru mendaftar, admin memverifikasi, guru mengelola soal, guru menjalankan kuis sesi atau kuis langsung, murid menjawab tanpa login, dan guru memantau hasil secara real-time.
2. Bank soal mendukung input manual, pindaian foto (OCR), dan unggahan berkas PDF/DOC/DOCX, dengan filter kelas, mata pelajaran, dan tingkat kesulitan.
3. Seluruh batasan penting sudah ditegakkan di kode: hanya guru `verified` yang mengelola soal, hanya pemilik soal/sesi yang dapat mengubahnya, dan hanya sesi `active` yang menerima jawaban.

## 5.2 Saran

1. Tetapkan alamat resmi, akun admin cadangan, dan jam layanan support, lalu gantikan semua penanda `[ISI MANUAL: ...]`.
2. Lengkapi seluruh screenshot pada Lampiran A dengan tampilan produksi (bukan data uji coba).
3. Sosialisasikan format soal standar (`1. Pertanyaan?` + `A) B) C) D)`) agar Scan Soal dan Upload File lebih akurat.
4. Tentukan kebijakan retensi sesi dan jawaban (kapan sesi ditutup dan berapa lama data disimpan).
5. Jika instansi membutuhkan export nilai, kelola profil, atau reset password mandiri, kembangkan sebagai fitur baru karena belum ada di kode saat ini.
